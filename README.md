# CryptoFlowPlus

CryptoFlowPlus is a distributed, scalable suite that leverages asynchronous and multi-threading for real-time cryptocurrency portfolio synchronization and valuation.

CryptoFlowPlus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoFlowPlus.git`
2. `cd CryptoFlowPlus`
3. Install in editable mode: `pip install -e .`

## Configuration

CryptoFlowPlus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
